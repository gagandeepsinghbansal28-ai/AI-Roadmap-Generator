# 🎓 AI Skill Roadmap Generator

An AI-powered web application that generates personalized learning roadmaps for students based on their qualification, interests, experience level, and available study time.

This project is designed especially to help rural and beginner students who lack proper career guidance and structured learning direction.

---

## 🚀 Features

- Personalized AI-generated skill roadmap
- Daily / Weekly structured learning plan
- Course overview and prerequisites
- Completely free learning resources
- Beginner to advanced project ideas
- Career opportunities guidance
- Downloadable roadmap (.txt format)

---

## 🛠️ Tech Stack

- **Python**
- **Streamlit** (Frontend + Web App Framework)
- **Google Gemini API (gemini-2.5-flash)**
- **python-dotenv**
- **JSON**
